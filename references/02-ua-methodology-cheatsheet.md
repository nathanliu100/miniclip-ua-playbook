# UA 方法论速查卡（Cheatsheet）

> 写脚本前 1 分钟扫一遍，确保每条素材方法论合格。

---

## 📐 3C 原则

每个创意元素必须服务于三个功能之一：

- **Context（语境）**：像内容，不像广告。平台原生化 CTR **+180–340%**
- **Clarity（清晰）**：单一卖点（One-Thing Rule）。单一卖点 CVR **+60–120%**
- **Curiosity（好奇心）**：开放循环 / 模式中断 / 社会证明 / 具体细节

## 🪝 4 层 Hook 系统（前 0.5–3 秒）

```
0s        0.3s       0.5s       1.0s       3.0s
│          │          │          │          │
Layer 1  ██████████████  视觉钩子 (模式中断：运动/色彩/人脸)
Layer 2        ████████████  文字钩子 (画面 1/3 位置, 4–8 词)
Layer 3        ████████████████  语言钩子 (提问/挑衅/证言)
Layer 4  ████████████████████████  音频钩子 (趋势音乐/音效)
```

| Hook 层数 | 相对 3 秒留存 |
|----------|--------------|
| 单层 | 1x |
| 2 层 | 1.8x |
| **3–4 层** | **2.8x** ← 目标 |

## 🎢 情感五段式（Hook → Problem → Solution → Proof → CTA）

```
0s    3s    8s    12s   20s   30s
┃─────┃─────┃─────┃─────┃─────┃
│ HOOK│PROB │ SOL │PROOF│ CTA │
```

| 阶段 | 时间 | 目标 | 休闲竞技类示例 |
|------|------|------|---------------|
| **Hook** | 0–3s | 抓注意 | 超能力爆炸特效 / 桌上足球视角 |
| **Problem** | 3–8s | 痛点激化 | 对手太强 / 排名上不去 / 被碾压 |
| **Solution** | 8–12s | 展示答案 | 升级 / 选新角色 / 解锁超能力 |
| **Proof** | 12–20s | 游戏实录 | 华丽进球 + Victory |
| **CTA** | 20–30s | 驱动安装 | Logo + "Play Now, It's Free!" |

> ⚠️ **跳过 Problem 阶段，转化率下降 45–65%**

## 🧠 注意力四象限

```
1. 自下而上 (Bottom-up) ──► 2. 情绪性 (Emotional)
   视觉/声音冲击              惊喜/恐惧/快乐
           │                         │
           ▼                         ▼
3. 认知性 (Cognitive)   ──► 4. 自上而下 (Top-down)
   熟悉事物/品牌               逻辑/解决问题
```

**公式**：成功创意 = **强力钩子** + **平台原生风格** + **视觉清晰度**

## 🔁 Fail / Upgrade / Win 循环（休闲竞技默认骨架）

```
失败（被碾压）→ 升级（抽卡/换角色/解锁）→ 赢回（爽感释放）
```

HB2 验证过的高潜力方向排序：
1. 🥇 Fail/Upgrade/Win 循环 → 30s 2D 实录
2. 🥇 超能力逆转 → 30s 2D/3D
3. 🥈 UGC 兴奋玩家 → 15–30s
4. 🥈 挑战型 ("你能进这球吗？") → 试玩广告
5. 🥉 叙事型（角色故事） → 30s 旁白
6. 🥉 电影级（慢动作 + 转播感） → 30s 3D

## 🔥 疲劳管理
